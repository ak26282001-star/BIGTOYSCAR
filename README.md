# Royal Designer NYC home page

Home page for a jewelry store (retail and wholesale): hero with the storefront photo, collections, wholesale, and visit details with directions.

- `index.html`: the page. Text in `[SQUARE BRACKETS]` is a placeholder to replace.
- `assets/css/styles.css`: design tokens, layout, and all motion (last section of the file)
- `assets/js/main.js`: scroll reveals
- `assets/img/storefront.jpg`: hero photo

Static site, with no build step. See [DEPLOYMENT.md](DEPLOYMENT.md) for what's required before going live.
