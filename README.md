# Dealership home page

Home page for a car dealership: hero, cars in stock (with body-type filter), how buying works, finance and trade-in, service, and a test-drive form.

- `index.html`: the page. Text in `[SQUARE BRACKETS]` is a placeholder to replace.
- `assets/css/styles.css`: design tokens, layout, and all motion (last section of the file)
- `assets/js/main.js`: header, hero load sequence, scroll reveals, stock filter, test-drive form
- `assets/js/config.js`: **test-drive form endpoint (edit before launch)**

Static site, with no build step. See [DEPLOYMENT.md](DEPLOYMENT.md) for what's required before going live.
