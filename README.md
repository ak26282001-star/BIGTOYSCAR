# Big Toys Customs

Marketing site for Big Toys Customs: a bespoke automotive build studio.

- `index.html`: the page, including the SVG car artwork sprite
- `assets/css/styles.css`: design system and layout
- `assets/js/main.js`: navigation, motion, build configurator, quote form
- `assets/js/config.js`: **quote endpoint, contact details, pricing (edit before launch)**

Static site, with no build step. See [DEPLOYMENT.md](DEPLOYMENT.md) for what's required before going live.
